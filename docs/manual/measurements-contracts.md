# 仕様に数値目標と条件・報酬を書く

## できること

整理された仕様ごとに、次の 2 つを書き残せます。

- **数値計測**: 何を、どの単位で、どう測り、どれくらいを目標にするか。実際に測った値も書けます。
- **契約**: どんな条件を満たしたら、何を、どれだけ、いつ渡すか。報酬はお金に限りません (アイテム、称号など)。

ここに書くのは「約束の記録」です。書いただけで実際に計測したり、報酬を配ったりはしません。

## 始める前に

- 仕様が「体系」に登録されている必要があります。[断片を残して仕様にまとめる](./fragments-to-specs.md) を参照してください。
- 書き込めるのは、プロジェクトでの役割が「オーナー」か「プランナー」の人です。

<a id="start"></a>

## 操作する

1. プロジェクトの「仕様」で「体系」を開き、仕様の見出しを押して開きます。
2. 下の「計測・契約を記載する」を開きます。
3. 数値計測なら「計測を追加」の欄に書きます。「指標」と「単位」は必須です (例: 指標「宝箱を開けてから中身が出るまでの時間」、単位「秒」、目標・判定条件「1 秒以内」)。
4. まだ測っていなければ「実測値」は空のままにします。測った値を書くときは、どこで測ったか (「観測の根拠」) も書きます。
5. 「追加して保存」を押します。
6. 契約なら「契約を追加」の欄に、成立条件・判定方法と根拠・報酬の内容と量と単位・付与時点・例外を書き、「追加して保存」を押します。
7. 書いた行を消すときは、表の「外す」を押します。

## 成功を確かめる

仕様を開くと、「数値計測」と「契約 (条件と報酬)」の表に書いた内容が並びます。
測っていない値は「未計測」、書いていない項目は「未定義」と表示されます。0 として扱われることはありません。

## 困ったとき

- 「未解決事項」が表示された: 書き漏れや食い違いがあります。たとえば、同じ指標なのに単位や期間が違う行、量はあるのに単位がない報酬などです。内容を確認して書き直してください。自動で直されることはありません。
- 「他の編集と競合しました。」: 別の人が同じ仕様を先に変えています。画面を読み込み直してからやり直してください。
- 「計測・契約を編集する権限がありません。」: 役割が「オーナー」か「プランナー」かを確認してください。
- 再構築で断片から仕様をまとめると、断片に書いた数値・条件・報酬も表に整理されます。確定前の「再構築案」に「確定後の計測・契約」として表示されるので、確かめてから確定してください。
