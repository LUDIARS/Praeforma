# Praeforma を使い始める

## できること

Praeforma は、企画者・デザイナー・プログラマーが同じプロジェクトを見ながら、
「何を作るか」を決めていくための場所です。

- 思いついたことや受けた指示を、形を気にせず「断片」として残せます。
- たまった断片を、整理された仕様にまとめ直せます。まとめた結果は版として記録されます。
- 仕様ごとに、数値の目標や「条件を満たしたら何がもらえるか」を書き残せます。
- UX・ドメイン (機能のまとまり)・アクター・シーンなど、企画の土台も同じプロジェクトで管理します。

## 始める前に

Praeforma を開ける状態で、プロジェクトを作るか、既存のプロジェクトに参加している必要があります。
仕様を書き換えられるのは、プロジェクトでの役割が「オーナー」か「プランナー」の人です。
それ以外の役割では、内容を読むことはできますが、登録や変更の操作は表示されません。

<a id="start"></a>

## 操作する

最初の成功までの道筋は次のとおりです。

1. [プロジェクトを作る](./create-project.md) — 一覧画面からプロジェクトを作ります。
2. [断片を残して仕様にまとめる](./fragments-to-specs.md) — 思いつきを断片として残し、「再構築」で仕様にまとめます。
3. [仕様に数値目標と条件・報酬を書く](./measurements-contracts.md) — まとめた仕様に、目標値や報酬の約束を書き添えます。

プロジェクトを開くと、上部に「概要」「UX」「シナリオ」「制約」などの項目が並びます。
画面に入りきらない項目は「その他」の中にあります。

## 成功を確かめる

プロジェクトの「仕様」を開き、「体系」に自分の仕様が並んでいれば、最初の一周は完了です。
仕様の版は「再構築・バージョンログ」に表示されます。

## 困ったとき

- 一覧が出ない: 「取得に失敗しました。」と出たら「再取得」を押してください。
- 登録の操作が見当たらない: 役割が「オーナー」か「プランナー」かをプロジェクトの管理者に確認してください。
