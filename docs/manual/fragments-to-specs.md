# 断片を残して仕様にまとめる

## できること

最初から整った仕様を書く必要はありません。思いついたことや受けた指示を「断片」として残し、
ある程度たまったら「再構築」でまとめ直して、整理された仕様にできます。
まとめる前の断片は記録として残るので、どの仕様がどの指示から来たかを後から追えます。

## 始める前に

- プロジェクトでの役割が「オーナー」か「プランナー」である必要があります。
- まとめた仕様は、どれかのドメイン (機能のまとまり) に属します。再構築の前に、「ドメイン」で少なくとも 1 つ登録しておいてください。

<a id="start"></a>

## 操作する

### 断片を残す

1. プロジェクトの「仕様」を開きます。
2. 「断片」を選びます。
3. 入力欄に思いついたことを書きます (例: 「宝箱を開けたら 1 秒以内に中身を見せたい」)。数値の目標や、条件と報酬も自由に書けます。
4. 「断片を登録」を押します。

### まとめて仕様にする

1. 「仕様」の上部にある「再構築・バージョンログ」を開きます。
2. 「再構築」を押します。「統合案を作成中…」の間は待ちます。
3. 「再構築案」が表示されます。追加・更新される仕様ごとに、変更前と変更後、出典になった断片が並びます。まとめられなかった断片は「保留する断片」に理由つきで出ます。
4. 内容を確認して「この内容で確定する」を押します。

### 自分で直接登録する

断片を経ずに、整った仕様を直接書くこともできます。

1. 「仕様」の「体系」を開きます。
2. 「仕様を登録」で、ドメインを選び、仕様コード・タイトル・説明を入れます。
3. 「仕様を登録」を押します。

## 成功を確かめる

- 断片を登録すると、一覧に表示され、仕様の版の最後の数字が 1 つ上がります。
- 再構築を確定すると、「体系」に仕様が並び、版の真ん中の数字が 1 つ上がります。「バージョンログ」に、変わった仕様と出典の断片が記録されます。
- 「リリースを記録」で記録すると、版の最初の数字が上がります。これは記録だけで、配布などは行いません。

## 困ったとき

- 「登録を確認できませんでした。入力は残っています。」: そのままもう一度「断片を登録」を押してください。同じ内容が二重に保存されることはありません。
- 再構築の確定で、資料が変わったという表示が出た: 案を作った後に断片や仕様が変わっています。もう一度「再構築」を押して案を作り直してください。
- 「登録できませんでした。仕様コードの重複・ドメイン・編集権限を確認してください。」: 同じ仕様コードが既にないか、ドメインを選んだかを確認してください。
- 断片の「実装状態」は、作ったものが実際に動くかを記録する欄で、仕様にまとめたかどうかとは別です。
