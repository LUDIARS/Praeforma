# プロジェクトを作る

## できること

ゲームや製品ごとにプロジェクトを作ります。断片・仕様・UX などはすべてプロジェクトの中に保存されます。

## 始める前に

所属するチームの ID が必要です。分からない場合はチームの管理者に確認してください。

<a id="start"></a>

## 操作する

1. 「プロジェクト一覧」の画面を開きます。
2. 「新しいプロジェクト」の「プロジェクト名」に名前を入れます (例: 「宝探しアドベンチャー」)。
3. 「チーム ID」に所属チームの ID を入れます。
4. 「作成」を押します。
5. 「作成したプロジェクトを開く」を押すと、作ったプロジェクトに移ります。

## 成功を確かめる

プロジェクト一覧に、作ったプロジェクトの名前が表示されます。
名前を押すとプロジェクトが開き、上部に「概要」などの項目が並びます。

## 困ったとき

- 「作成に失敗しました。」と出た: 名前とチーム ID が入っているか確認して、もう一度「作成」を押してください。
- 一覧が長い: 下の「もっと見る」で続きを表示できます。並びは更新が新しい順です。
