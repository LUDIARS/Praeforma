# シナリオ表示が横にはみ出す

- Date: 2026-09-08
- Area: UXデザインのシナリオ選択

## Summary

necoから「シナリオのカバーが横にはみ出している。ここはシナリオをプルダウンで表示」と報告された。

## Evidence / Cause

ux-design.cssは画面をviewport幅で拡張し、親コンテンツの幅を超える指定を持っていた。シナリオ選択は260pxサイドバーで、スマホではカードを横スクロール表示していた。接続ブラウザが無いため実画面の再現は未確認。

## Fix Requirements

シナリオはselectで選択し、編集領域と縦に並べる。親幅100%とminmax(0, 1fr)で画面を収め、長いシナリオ名は折り返す。TODOはプロジェクト概要へ移す。

## Verification

Revisorで320px/375px幅とデスクトップ幅を確認する。長いシナリオ名でもページ横幅を超えず、プルダウン選択で該当シナリオへ切り替わること。新規シナリオ作成・既存シナリオ編集・TODOからの遷移を確認する。
