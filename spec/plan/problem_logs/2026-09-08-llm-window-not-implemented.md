# PfのLLMウインドウが表示されない

- Date: 2026-09-08
- Area: AI相談の入口

## Evidence / Cause
利用者より「LLMウインドウ出ないんだが」。mainのApp.tsxに表示ボタンもウインドウも存在せず、依頼が調査段階のまま未実装だった。キャッシュや表示不具合による退行ではない。

## Fix Requirements
ヘッダからPC・スマホ共通の畳めるウインドウを開く。初回送信でCcセッションを起動し、会話の紐付けをユーザー・プロジェクト単位で保存する。30分無応答で接続を止め、再接続で同じ会話を再開する。明示Clearまで保持する。

## Verification
ヘッダ表示、スマホ幅、開閉と画面遷移、初回送信、切断・再接続、Clear、Cc未設定時の明示エラー、二重起動防止、他ユーザーの会話を参照できないことを確認する。
