# 数値計測と条件・報酬の契約を仕様に記載する

## 目的

機能の計測仕様と契約をフラグメントから構造化仕様へ引き継ぎ、仕様から参照できるようにする。

## 作業

1. 計測対象・指標・単位・方法・期間・目標/判定条件と観測根拠を構造化仕様に追加する。
2. 契約対象・成立条件・判定根拠・報酬内容/量/単位・付与時点・例外を記載できるようにする。
3. 仕様画面の入力・表示・版差分に対応させ、レコンストラクションで原文の数値/条件/報酬を保存する。
4. 単位や判定条件の食い違いを未解決事項として提示し、未計測を0と扱わない。

## 完了条件

各種仕様に数値計測と契約を記載でき、再構築後も出所と版を追える。仕様記載のみで実計測や報酬付与を実行しない。

## スコープ

Praeformaの仕様データ・API・編集UI・レコンストラクションとspec/。
