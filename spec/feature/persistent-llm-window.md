# Pf内の永続AI相談ウインドウ

- PF-CHAT-1: プロジェクト画面のヘッダ横「AI相談」からPC・スマホ共通で開閉する。Pf内で最前面に表示する。畳む操作はいつでも可能で、会話の終了やClearを意味しない。
- PF-CHAT-2: 最初の送信でCcのClaudeセッションを専用worktreeにspawnする。開くだけではspawnしない。ユーザー・プロジェクト単位の紐付けをDBに保存し、Ccが割り当てたセッションだけを読み書きする。owner/plannerが利用可能。
- PF-CHAT-3: 30分やり取りが無ければブラウザの取得を止める。会話・Ccプロセスは保持する。再接続時、activeなら同じCcセッションへ接続し、終了済みならCcのforkと同じtranscriptアンカーを使ってresumeする。lostやアンカー不明時は新規会話へ黙って切り替えずエラーにする。
- PF-CHAT-4: 明示Clearで紐付いたCcプロセスを停止し、Pfの会話をリセットする。Ccの監査ログや仕様フラグメントは削除しない。
- PF-CHAT-5: 送信内容を仕様フラグメントにも保存する。CASで同時起動・送信を防ぐ。通信不明時は自動再送・再spawnせず状態を表示する。初期起動結果が不明な間は相関マーカーでCcを照会し、無関係なセッションを採用しない。
- PF-CHAT-6: 接続先はPRAEFORMA_CC_URLまたはExcubitorのCONCORDIA_URLを使う。ブラウザからCcへ直接接続せずPfが中継する。

表示は各Ccセッションの直近100メッセージとPfから送信した内容。Cc本体には全履歴が残る。権限確認などは確認事項として表示する。OS全体の最前面表示ではなくPf内の表示。

検証: `server/src/lib/__tests__/llm-chat.test.ts`（起動競合・永続化・ユーザー分離・同一Cc再接続・resume引数・Clear・フラグメント保存）。画面ではモバイル幅、開閉、30分切断、接続失敗、実Ccでの応答を確認する。
