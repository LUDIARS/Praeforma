# コアドメイン内でのビジネスドメイン配置

コアドメインのカードを展開すると、未配置のビジネスドメインを選択して追加できる。

- PF-DA-1: 未配置は同一プロジェクトで分類が business、親が未設定のドメインとする。未分類・コア・配置済みのドメインは選択しない。
- PF-DA-2: 選択したドメインの説明を表示する。追加は既存の親子関係へ保存し、名前・説明・定義を保持する。
- PF-DA-3: 追加後は子ドメイン一覧と選択候補を更新する。候補が無い場合はその旨を表示し、追加を無効にする。処理中の重複送信を防ぐ。
- PF-DA-4: owner / planner のみ配置可能。サーバでも分類・プロジェクト・未配置を検証し、同時配置による上書きや循環を拒否する。失敗時はエラー表示と一覧の再取得を行う。

API: `POST /api/projects/:pid/domain-definitions/:did/business-domains/:bid`

確認: `server/src/lib/__tests__/domain-assignment.test.ts`（保存・同時追加・循環・別プロジェクト・分類・権限）。画面ではコア展開→候補選択→追加→子一覧と候補の更新を確認する。
